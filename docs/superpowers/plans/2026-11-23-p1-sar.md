**Owner:** P1 · **Branch:** `sar/synthetic` (branched from `main` after the day-0 merge) · **Runs in parallel with:** the P2 and P3 plans.

**Goal:** Replace the placeholder `SarData` with synthetic MSTAR-style chips, handcrafted features, a small CNN, speckle perturbation and rendering. All of it must pass the shared conformance test unchanged.

**Architecture:** The package is `radar/sar/`, split into:
- `synth.py`: chip generation and speckle
- `features.py`: HOG + GLCM + intensity statistics
- `cnn.py`: the model
- `__init__.py`: the `SarData` class that wires them into the contract

**Tech Stack:** numpy, scikit-image, torch, matplotlib

**Spec:** `docs/superpowers/specs/2026-11-23-mvp-implementation-design.md` (the "P1 SAR" section and the contract)

## Global Constraints

- Edit only `radar/sar/`, `tests/test_contract_sar.py` and `results/sar/`. Never touch `radar/contracts.py`, `radar/core/` or `app/`. If you need a change there, tell P3.
- Keep the placeholder's public surface exactly as it is:
  - class `SarData`
  - `name="sar"`
  - `perturbation="speckle strength"`
  - `levels=[0.0, 0.25, 0.5, 0.75, 1.0]`
  - class names `2S1, BMP2, BRDM2, BTR60, BTR70, D7, T62, T72, ZIL131, ZSU234` (in that order)
  - `foe_classes = frozenset({"T62", "T72", "ZSU234", "2S1", "BMP2"})`
- Chips are `(N, 64, 64)` float32 with values in [0, 1].
- **Speckle strength** `s` means multiplicative gamma noise with mean 1 and standard deviation `s`. `s = 0` means no noise. The training data draws `s` uniformly from [0, 1].
- Synthetic depression is 17° for train and 15° for test (the MSTAR protocol, D5). Record it in `meta_test["depression_deg"]`, and record the aspect in `meta_test["aspect_deg"]`.
- All randomness comes from `np.random.default_rng(seed)` or seeds derived from it. Never use global numpy random state.
- One full run, `python -m radar.core.run --data sar`, must take 10 minutes or less on a laptop CPU.

## Review Focus

- **Rotation must not decide the class.** Two classes at the same aspect must differ in their clean chips. Otherwise accuracy hits chance and the demo looks broken.
- **Speckle must stay in range.** Speckle at `s = 1.0` must keep values inside [0, 1] after clipping, with no NaNs.
- **`load("mstar")` must not crash the platform's error path.** It raises `NotImplementedError`; any other unknown source raises `ValueError`.
- **`perturb` on a single sample** (`x[None]`) must work, because the demo's Predict page calls it that way.
- **`features` must be per-sample.** Running on a batch of 1 must give the same row as running on the full batch.

### Task 1: Synthetic chip generator and speckle

**Files:**
- Create: `radar/sar/synth.py`
- Test: `tests/test_contract_sar.py`

**Interfaces:**
- Produces:
  - `CLASS_NAMES: list[str]`
  - `FOE: frozenset[str]`
  - `make_clean(labels: np.ndarray, aspects_deg: np.ndarray, rng: np.random.Generator) -> np.ndarray`: returns `(N, 64, 64)` float32 in [0, 1]
  - `apply_speckle(clean: np.ndarray, strength: float | np.ndarray, rng) -> np.ndarray`: same shape, clipped to [0, 1]. Strength is either a scalar or one value per sample, shape `(N,)`.

- [ ] **Step 1: Write the failing tests**

```python
import numpy as np
from radar.sar.synth import CLASS_NAMES, FOE, make_clean, apply_speckle

def test_classes_and_foe():
    assert len(CLASS_NAMES) == 10 and FOE == {"T62", "T72", "ZSU234", "2S1", "BMP2"}

def test_clean_chip_shape_range_determinism():
    lab, asp = np.arange(10), np.zeros(10)
    a = make_clean(lab, asp, np.random.default_rng(0))
    assert a.shape == (10, 64, 64) and a.dtype == np.float32 and a.min() >= 0 and a.max() <= 1
    assert np.array_equal(a, make_clean(lab, asp, np.random.default_rng(0)))

def test_classes_differ_at_same_aspect():
    a = make_clean(np.arange(10), np.zeros(10), np.random.default_rng(0))
    d = [np.abs(a[i] - a[j]).mean() for i in range(10) for j in range(i + 1, 10)]
    assert min(d) > 0.01

def test_speckle_zero_is_identity_and_grows():
    c = make_clean(np.arange(10), np.zeros(10), np.random.default_rng(0))
    assert np.array_equal(apply_speckle(c, 0.0, np.random.default_rng(1)), c)
    e = [np.abs(apply_speckle(c, s, np.random.default_rng(1)) - c).mean() for s in (0.25, 0.5, 1.0)]
    assert e[0] < e[1] < e[2]
    hi = apply_speckle(c, 1.0, np.random.default_rng(1))
    assert np.isfinite(hi).all() and hi.min() >= 0 and hi.max() <= 1
```

- [ ] **Step 3: Implement `synth.py`**

- **Per-class template:** 6 to 12 point scatterers at fixed (x, y) offsets and amplitudes, drawn once from `default_rng(1000 + class_index)` so the templates are independent of the data seed.
- **Rendering a chip:**
  1. Rotate the scatterer offsets by the aspect angle.
  2. Add small per-sample jitter of about 1 pixel from `rng`.
  3. Splat each scatterer as a Gaussian blob (σ about 1.5 px) onto a 64×64 grid, plus a dim rectangular "body" shadow.
  4. Normalise each chip by its max.
- **Speckle:** `clean * rng.gamma(1/s**2, s**2, clean.shape)` for `s > 0`, then clip to [0, 1].

from radar.sar.features import sar_features
from radar.sar.cnn import SarCNN

def test_features_per_sample_and_finite():

- [ ] **Step 3: Implement the features and the CNN**

- **Features**, concatenated per chip:
  - HOG: `skimage.feature.hog`, `pixels_per_cell=(8, 8)`, `cells_per_block=(2, 2)`
  - GLCM: `graycomatrix` on the chip quantised to 32 levels, distances `[1, 2]`, angles `[0, π/4, π/2, 3π/4]`; take the mean over angles of `graycoprops` contrast, homogeneity, energy and correlation
  - Intensity statistics: mean, std, skew, kurtosis, and the 90th and 99th percentiles
- **CNN:** three blocks of `Conv(3×3)`, BatchNorm, ReLU, `MaxPool(2)` with 16, 32 and 64 channels, then `AdaptiveAvgPool2d(1)`, `Dropout(0.3)` and `Linear(64, n_classes)`.
