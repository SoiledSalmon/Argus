**Goal:** Replace the placeholder `SignalData` with 8 synthetic radar waveform classes, AWGN at exact SNRs, time-frequency features, a spectrogram CNN and rendering. All of it must pass the shared conformance test unchanged.

## Global Constraints

- Edit only `radar/signal/`, `tests/test_contract_signal.py` and `results/signal/`. Never touch `radar/contracts.py`, `radar/core/` or `app/`. If you need a change there, tell P3.
- Keep the placeholder's public surface exactly as it is:
  - class `SignalData`
  - `name="signal"`
  - `perturbation="SNR (dB)"`
  - `levels=[-10, -5, 0, 5, 10, 15, 20]`
  - class names `LFM, Costas, Barker, Frank, P1, P2, P3, P4` (in that order)
  - `foe_classes = frozenset({"Costas", "Frank", "P3", "P4"})`
- Samples are `(N, 1024)` complex64. Clean signals have unit average power.
- Training SNR is uniform on [−10, +20] dB per sample (D4). The test set uses the same distribution, records `meta_test["snr_db"]`, and keeps `X_test_clean`.
- `to_cnn_input` returns `(N, 1, 64, 64)` float32.
- All randomness comes from `np.random.default_rng(seed)` or seeds derived from it.
- One full run, `python -m radar.core.run --data signal`, must take 10 minutes or less on a laptop CPU.

## Review Focus

- **SNR must be exact for the robustness curve.** `perturb(clean, L)` must give a measured SNR within ±1 dB of `L`, measured per sample and averaged over a batch.
- **Polyphase classes must not be identical.** Frank, P1, P2, P3 and P4 must give different phase sequences for the same code length, or the confusion matrix collapses.
- **Spectrograms must stay finite at low SNR.** At −10 dB the log-magnitude must contain no `-inf` (add a small epsilon before the log).
- **`perturb` on a single sample** (`x[None]`) must work, because the demo calls it that way.
- **Features must stay finite** for a pure-noise-like sample (−10 dB): no divide-by-zero in moment ratios.

```python
import numpy as np
from radar.signal.waveforms import CLASS_NAMES, FOE, generate, make_clean

def test_classes_and_foe():
    assert CLASS_NAMES == ["LFM", "Costas", "Barker", "Frank", "P1", "P2", "P3", "P4"]
    assert FOE == {"Costas", "Frank", "P3", "P4"}

def test_unit_power_shape_dtype_determinism():
    for c in CLASS_NAMES:
        x = generate(c, np.random.default_rng(0))
        assert x.shape == (1024,) and x.dtype == np.complex64
        assert abs(np.mean(np.abs(x) ** 2) - 1) < 0.05
        assert np.array_equal(x, generate(c, np.random.default_rng(0)))

def test_polyphase_codes_differ():
    from radar.signal.waveforms import polyphase_phases
    ph = {c: polyphase_phases(c, 16) for c in ["Frank", "P1", "P2", "P3", "P4"]}
    keys = list(ph)
    assert all(not np.allclose(ph[a], ph[b]) for i, a in enumerate(keys) for b in keys[i + 1:])
```

- [ ] **Step 3: Implement `waveforms.py`**

Also export `polyphase_phases(cls: str, n_chips: int) -> np.ndarray`, using the standard Frank, P1, P2, P3 and P4 phase formulas (Levanon & Mozeson). For Frank, P1 and P2, `n_chips = M²`.

Every sample gets:
- a random carrier offset in ±0.1 normalised frequency
- a random start phase
- a random pulse start delay of 0 to 128 samples, with zeros outside the pulse
- normalisation to unit power over the full 1024 samples

Parameter ranges:

| Class | Parameters |
|---|---|
| LFM | bandwidth 0.05 to 0.4 normalised, random sweep direction |
| Costas | random Costas sequence via Welch construction, with prime p in {5, 7, 11}, giving 4, 6 or 10 hops |
| Barker | code length 7, 11 or 13 |
| Frank, P1 | M in {4, 5, 6} |
| P2 | M in {4, 6} |
| P3, P4 | N in {16, 25, 36} |

For the coded classes, chips are 8 to 20 samples long.

### Task 3: Features, spectrogram and CNN

**Files:**
- Create: `radar/signal/features.py`, `radar/signal/cnn.py`
- Test: `tests/test_contract_signal.py` (append)

**Interfaces:**
- Produces:
  - `signal_features(X) -> np.ndarray`: `(N, F)` float32, finite
  - `spectrogram(X) -> np.ndarray`: `(N, 1, 64, 64)` float32, each sample standardised to zero mean and unit variance
  - `SignalCNN(n_classes) -> nn.Module`: maps `(N, 1, 64, 64)` to logits

- [ ] **Step 1: Write the failing tests**

```python
import torch
from radar.signal.features import signal_features, spectrogram
from radar.signal.cnn import SignalCNN

def test_features_and_spectrogram_finite_at_low_snr():
    c = make_clean(np.arange(16) % 8, np.random.default_rng(0))
    n = add_awgn(c, -10, np.random.default_rng(1))
    F, S = signal_features(n), spectrogram(n)
    assert F.shape[0] == 16 and F.dtype == np.float32 and np.isfinite(F).all()
    assert S.shape == (16, 1, 64, 64) and S.dtype == np.float32 and np.isfinite(S).all()
    assert np.allclose(signal_features(n[2:3])[0], F[2], atol=1e-5)

def test_cnn_logits_shape():
    assert tuple(SignalCNN(8)(torch.zeros(2, 1, 64, 64)).shape) == (2, 8)
```

- [ ] **Step 2: Run the tests and confirm they fail**

Run: `pytest tests/test_contract_signal.py -v`
Expected: the 2 new tests fail with an import error.

- [ ] **Step 3: Implement**

- **Features**, concatenated per sample:
  - From the unwrapped phase and its derivative (the instantaneous frequency): mean, std, skew, kurtosis, and the std of the second difference
  - From the envelope |x|: mean, std, and peak-to-average ratio
  - From the FFT: spectral centroid, bandwidth, flatness, and the frequency of the peak bin
  - Normalised moments and cumulants: |C20|, |C21|, |C40|, |C41|, |C42|, normalised by C21². Add an epsilon to every denominator.
- **Spectrogram:**
  1. `scipy.signal.stft(x, nperseg=128, noverlap=112, return_onesided=False)`
  2. `fftshift` along frequency
  3. `log(|Z| + 1e-6)`
  4. Resize to 64×64 with `skimage.transform.resize`
  5. Standardise per sample
- **CNN:** the same shape as a small 3-block conv net (16, 32, 64 channels, BatchNorm, ReLU, MaxPool), then global average pooling, `Dropout(0.3)` and `Linear(64, n_classes)`.
